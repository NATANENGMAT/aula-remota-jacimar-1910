Explore · Média

Média: repartir igualmente.

O que é? A média aritmética é a soma dos valores dividida pela quantidade de valores.

O que representa? Um ponto de equilíbrio do conjunto: quanto caberia a cada um se o total fosse repartido igualmente.

Imagine que você bebeu uma dose de água por dia:
Dia 1: 100 mL · Dia 2: 200 mL
Dia 3: 300 mL · Dia 4: 200 mL.

Ao longo dos 4 dias, você bebeu 800 mL no total. Toque para repartir esse total igualmente pelos 4 dias.

100 mL
200 mL
300 mL
200 mL
Média =100 + 200 + 300 + 2004= 200 mL/dia

Como ler a fração? Em cima fica o consumo total: 800 mL. Embaixo fica o período: 4 dias. O resultado é 200 mL por dia, em média.

O que o cálculo indica? É como se você tivesse bebido 200 mL em cada dia: o total continuaria sendo 800 mL. A média de consumo é 200 mL/dia; ela resume o período, mesmo que o consumo tenha variado de um dia para outro.

Para pensar no futuro: médias de períodos comparáveis ajudam a perceber se uma quantidade está aumentando ou diminuindo e a planejar. Uma única média não garante o próximo valor.

Cada copo representa o consumo de um dia. Atenção: 800 mL é o total dos 4 dias; 200 mL/dia é a média diária.

Explore · Moda

Moda: o que mais se repete.

O que é? A moda é o valor com maior frequência: aquele que aparece mais vezes no conjunto.

O que representa? O resultado mais comum entre os dados observados. A média equilibra os valores; a moda conta as repetições.

Toque no valor que mais se repete neste exemplo didático.

100200200300
Moda é o valor mais frequente. Se nenhum se repete, o conjunto é amodal.

O que podemos deduzir? Se 200 aparece mais vezes, ele foi o resultado mais comum nesta amostra.

E para o futuro? Em muitos registros comparáveis, uma moda estável pode sugerir um resultado comum em novas observações, se as condições continuarem semelhantes. É uma hipótese para orientar decisões, não uma certeza. Se níveis altos se repetem, isso já justifica atenção e planejamento para reduzir a exposição e combater as fontes de poluição; não precisamos esperar outra ocorrência para agir.

Neste exemplo: só temos 4 valores. Eles ensinam a identificar a moda, mas são poucos para sustentar uma previsão.
